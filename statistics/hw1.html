Questo progetto esplora i fondamenti della pulizia dei dati e del preprocessing.


L'obiettivo principale è stato identificare i valori anomali in un dataset di misurazioni fisiche e preparare la struttura dati per un successivo modello di regressione lineare. Sono state applicate tecniche di normalizzazione Z-score per uniformare la scala delle variabili.

# Importazione dataset
dataset <- read.csv("dati_grezzi.csv")

# Rimozione valori nulli
dataset_pulito <- na.omit(dataset)

# Calcolo dello Z-score per la colonna 'pressione'
dataset_pulito$pressione_z <- scale(dataset_pulito$pressione)

# Filtraggio outlier (|Z| > 3)
dataset_finale <- subset(dataset_pulito, abs(pressione_z) <= 3)
