Elliptic Curve Cryptography: Toy Model of Public-Key Derivation


This project demonstrates how asymmetric public-key cryptography operates using Elliptic-Curve Scalar Multiplication, the foundational mechanism behind Ethereum's secp256k1 standard.


Using a simplified model over a finite field—the curve y² ≡ x³ + 7 (mod 17) with generator point G = (1, 5)—the system derives a public key Q = kG for a private scalar k = 6 via iterative point addition and modular arithmetic.


Beyond the forward computation, the project explores the statistical behavior of the resulting coordinates, contrasting the algebraic structure of the Elliptic Curve Discrete Logarithm Problem (ECDLP) as a trapdoor one-way function with the pseudo-random avalanche dynamics typical of cryptographic hash algorithms.
